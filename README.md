# polyhedron_modification
This repository is dedicated to a modification of the polyhedron project version "Polyhedron image with hidden line removal without optimization".
The modification solves the following problem: We call a point in space "good" if it is located at a distance strictly less than 2 but strictly greater than 1 from the plane z=−3. Modify the reference design so that the following characteristic of a polyhedron is determined and printed: the sum of the areas of faces, no more than two of whose vertices are "good" points.
The presented solution can be generalized for arbitrary numbers in the condition by making a minimal change.

Link to the original project: https://github.com/eroganov/polyhedron
